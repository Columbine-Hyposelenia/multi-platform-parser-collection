# B站 Bilibili 解析方案

## 平台分类（终审版）

| 角色 | 项目名称 | 目录位置 | 登录要求 |
|------|---------|---------|---------|
| **主专用解析** | bilibili-parser | [`./bilibili-parser/`](./bilibili-parser/) | 免登录（基础画质）/ 扫码登录（4K/VIP） |
| **补足：8K/杜比/Hi-Res** | BBDownT | [`./BBDownT/`](./BBDownT/) | 免登录（基础）/ 需大会员（8K/杜比） |
| **备用专用解析** | yt-dlp | [`../universal/yt-dlp/`](../universal/yt-dlp/) | 免登录 |

## 主用：bilibili-parser

- **技术栈**: Web 应用（Node.js 后端 + 前端）
- **覆盖媒体**: 视频、番剧、课程、电影、纪录片、合集、分P
- **质量**: 免登录可解析基础画质（1080P 及以下），扫码登录后获取 4K/VIP 画质
- **网页部署**: 原生 Web 服务，自带前端界面和 API 接口，可直接集成
- **特点**: 视音完整/分离下载、仅音频、封面下载，MP4/FLV 格式，VIP 权限检测

## 补足：BBDownT（8K/杜比视界/Hi-Res）

> 主用 bilibili-parser 不支持 8K 和杜比视界，BBDownT 作为补足项，专门覆盖超高质量格式。
> 补足项紧跟主用，不另列主用，不与备用混放。

- **技术栈**: .NET / C#（CLI）
- **覆盖媒体**: 视频（含 8K、HDR、杜比视界、Hi-Res 音频）、番剧、互动视频
- **质量**: B站下载质量天花板，支持平台所有高级格式
- **网页部署**: 通过后端封装为 HTTP API 调用（CLI → API 包装）
- **登录要求**: 基础画质免登录，8K/杜比视界/Hi-Res 需大会员登录（Cookie/SESSDATA）

## 备用：yt-dlp

- **技术栈**: Python
- **覆盖媒体**: B站视频，多清晰度流
- **质量**: 免登录获取平台可用最高画质
- **网页部署**: Python 库嵌入后端，或封装 API
- **适用场景**: 主用和补足均因环境或接口变更失效时备用

## 注意事项

- 4K 及以上、杜比视界等需大会员账号权限
- DASH 格式音视频分离，需 FFmpeg 合并
- BBDownT 为 CLI 工具，生产环境建议封装 HTTP API
